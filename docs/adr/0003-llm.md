# ADR-003 — LLM: Anthropic Claude, tool-use, temperature 0

## Decision
Anthropic Messages API with structured tool calling. Closed action vocabulary. Temperature 0. Every request/response persisted as a cassette.

## Why
Tool schemas force the model to emit the same actions the replay executor can run. Discovery compiles to an artifact; it does not become the runtime.

## Trade-off
Vendor coupling. Isolated behind `handspan.llm.client`.
